# Codeforces Problems Bot

Telegram bot for searching Codeforces problems by difficulty and topics.

## Features
- Hourly updates of problems from Codeforces
- Search problems by difficulty and topics
- Get problem statistics and links

## Setup
1. Clone the repository
2. Create `.env` file with `TELEGRAM_TOKEN`
3. Run `docker-compose up`

## Commands
- `/start` - Start interaction
- `/search` - Search problems by name
- `/show` - Show selected problems
